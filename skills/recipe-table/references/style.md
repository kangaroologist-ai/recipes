# 已确认的样式

这些都是用户逐条看过、提过意见后定下来的。改 `scripts/render_recipe.py` 时保持它们；想改其中某条，先问用户。

## 共通

- 材料格先写名称，用量靠右对齐，让一列用量上下对齐。
- 步骤格写动作，下面一行小字写时长；等待的步骤在时长后加“· 等待”。
- 标题下一行摘要：总时长、份数、每份热量和蛋白质。
- 时间线：底部有分钟刻度（间隔自动选 1/2/5/10… 分钟，最多约 8 格；结尾时刻离最后一个刻度太近时去掉那个刻度，避免数字挤在一起），每个刻度有竖向参考线，每行有横向分隔线，条形是实心的。
- 营养表：所有数值一位小数；单位用灰色小字跟在名称后面；整份列 = 每份 × 份数。
- 不放图例，不放营养表下面的说明小字。
- 不用虚线。

## 对话里的 widget

- 不用颜色区分，只用实线边框。用户觉得对话里的颜色看不清。
- 时间线里动手的步骤用深色条，`passive` 步骤（静置、热锅等）用浅灰条。
- 表格文字可换行，列宽和图片版一样按时长大致成比例。
- 颜色都用 visualizer 的 CSS 变量，深色模式自动适配。

## 图片版（`--png` / `--table-png`）

- 整体是一张卡片：浅灰蓝底色上一张白色圆角卡片，细边框加很淡的阴影，四周留白一致。
- 配色冷静、偏冷色，不用暖色：备料/混合是浅青绿，加热是浅灰蓝，等待是浅灰；时间线条形用对应的深一号颜色。
- 相邻两列同一阶段时一深一浅交替（按列号奇偶），避免两个同色格子贴在一起看不出边界。
- 每个格子都有深灰实线边框，不能只靠颜色区分格子。
- 文字可以换行，不让长名称把表格撑宽：材料列固定宽度，名称换行、用量靠右不换行；步骤动作尽量短，避免一个词被拆开。
- 步骤列宽大致和时长成比例（有上下限），7 分钟的静置看起来比 1 分钟的拌匀宽。
- 只要配方表的图片（`--table-png`）：只留标题和下面那行摘要，其他文字（分节标题、时间线、营养表）都不要。中文、英文各一张。
- 生成方式：脚本先拼出 HTML，再用 wkhtmltoimage（老版 WebKit）截图成 PNG，2 倍分辨率。它不支持 CSS 变量、grid、flex，布局用表格、inline-block 和绝对定位。渲染后按卡片外留白裁掉多余画布。
